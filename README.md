Why I Built It

Choosing the right career can be confusing for students because they may not clearly understand their strengths, interests, skills, or available career opportunities. CareerFodge-AI was created to provide personalised career guidance instead of generic suggestions. It connects a student's profile with suitable careers, identifies skill gaps, and provides a clear path for skill development.

⭐ Core Features

- 🤖 AI-Based Career Recommendations – Personalised career suggestions based on student profiles.
- 👤 Profile Analysis – Analyses interests, strengths, preferences, and experience.
- 🎯 Career Matching – Matches students with suitable career paths.
- 🧩 Skill-Gap Detection – Identifies important skills that need improvement.
- 🛣️ Personalised Career Paths – Provides step-by-step career routes.
- 📚 Learning Guidance – Suggests courses, certifications, and learning resources.
- 🔍 Career Exploration – Helps compare careers, qualifications, and typical career paths.
- 📈 Progress Tracking – Supports continuous improvement through feedback.
